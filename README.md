# 📊 Dashboard Analítico de Vendas

Este projeto é uma aplicação interativa desenvolvida em **Python** utilizando o framework **Streamlit**. O objetivo é fornecer uma visão clara e dinâmica da performance de vendas de uma organização, permitindo análises por categoria de produto, região e desempenho individual de vendedores.

---

## 🚀 Funcionalidades

- **Tratamento de Dados Inteligente:**
    - Concatenação de `Primeiro Nome` e `Sobrenome` para garantir a unicidade de vendedores e evitar conflitos entre homônimos.
    - Limpeza automática de espaços em branco nos nomes das colunas (`strip`) para garantir a integridade do processamento.
- **Gráficos Interativos:**
    - **Vendas por Categoria:** Visão volumétrica por tipo de produto.
    - **Desempenho por Região:** Participação percentual de cada loja.
    - **Evolução Temporal:** Gráfico de linha demonstrando a tendência de vendas ao longo do tempo.
    - **Top 10 Vendedores:** Ranking dos melhores profissionais com base no volume total de vendas.
- **Filtros Dinâmicos:** Filtre todo o dashboard simultaneamente por Loja ou Categoria através da barra lateral.
- **Interface Organizada:** Navegação por abas (Dashboards, Tabelas Dinâmicas e Base de Dados Tratada).
